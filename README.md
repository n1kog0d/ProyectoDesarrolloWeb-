-Desarrolladores: Rafael Garrido, Alberto Arriagada y Nicolás Zambrano. 
Enlace del repositorio: https://github.com/n1kog0d/ProyectoDesarrolloWeb-/tree/main
-De los proyectos disponibles, escogimos la plataforma web de música. Proyecto desarrollado solamente en HTML, CSS y Javascript y trabajado sobre el framework de Bootstrap. 
-Las carpetas de la página que se encuentran en los directorios /var/www/html son: 
*audios: Donde se encuentran todos los archivos .mp3 que se utilizan en el proyecto como audios de canciones en el apartado de "categorias". 
*css: Donde se encuentran los archivos .css que se utilizan para el desarrollo de la página y su diseño; en este caso solo  el archivo "estilos.css".
*HTML: Donde se encuentran todos los archivos .HTML que representan una pestaña dentro de la página, como el index (página principal), el login, el register y el perfil hasta este momento. 
*img: Donde se encuentran múltiples imágenes utilizadas en el proyecto como portadas o en el carrusel de la página principal. Van desde archivos .jpg como .webp.
*javascript: Donde se encuentran todos los archivos .javascript que se utilizan para el desarrollo de la página y sus funcionalidades; en este caso solo el archivo "funciones.js".
-Dentro de las principales funcionalidades desarrolladas hasta el momento se encuentra: 
*Login y Register que  a pesar de no estar conectados a una base de datos están diseñados para su posterior implementación y simulan un correcto funcionamiento. 
*Pagina principal con botones funcionales que redirigen correctamente en función de los apartados a los que pertenecen.
*Catálogo que presenta diferentes tipos de géneros musicales con un botón que permite escuchar y pausar una canción perteneciente al género elegido. 
*Perfil que hasta el momento principalmente simula un perfil junto a sus seguidores, playlist y demás; que posteriormente se implementará junto a la base de datos.
